# Huangli Calendar 黄历

A Chinese tear-off almanac that hangs on a metal bar. Every page is worked out for its real date — lunar day, solar term, the day's 宜 / 忌, moon phase, nine-star chart. Pull a page off by hand, write on it with the pen on the chain, and save a page as an image.

Live: https://shuyii0315-arch.github.io/huangli-calendar/

Just the calendar (for embedding): https://shuyii0315-arch.github.io/huangli-calendar/calendar.html

Lunar data from [lunar-javascript](https://github.com/6tail/lunar-javascript) (MIT), bundled into the page so it works offline.

Design by Shuyi Yuan.
